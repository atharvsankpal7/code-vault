# code-vault
things I code while learning something new



I use LLMs to generate the code for me when to write code decisions have been made but the code writing is boilerplate which can't be done by IDEs.

That code is 100% read by me line by line. The commits where I use AI have that given model as co-author attached to it in a given commit.

100% of the code will be generated by AI for the given commit as that is just a grunt work i don't want to do, I'll review it.
