# code-vault
things I code while learning something new


Most of the code is handwritten(cause I enjoy writing code by hand).

However, I use LLMs to generate the code for me when decisions have been made by me in a psuedo code format but the code writing is boilerplate which can't be done by IDEs and writing it by hand will eat up the productivity of mine where I learn nothing while writing that code.

That code is 100% read by me line by line. The commits where I use AI have that given model as co-author attached to it in a given commit.

for the given commit 100% of the code will be generated by AI as that is just a grunt work i don't want to do, I'll review it.
